# Winter Night — Lively Wallpaper

![Winter Night Preview](preview.gif)

An animated ASCII winter night featuring swaying pine trees, falling snow, twinkling stars, a glowing moon, and a crackling campfire that lights the forest around it. Everything is drawn from text characters and loops seamlessly.

## How to Install
1. Download and install **[Lively Wallpaper](https://rocksdanister.com)**.
2. Download `winter_night.zip` from the **[Latest Release]([https://github.com](https://github.com/swisherr182/winter-night-lively-wallpaper/releases/tag/v1.0))** page.
3. Drag and drop the downloaded `.zip` file directly into your Lively Wallpaper window.
