# Winter Night — Lively Wallpaper

![Winter Night Preview](preview.gif)

An animated ASCII winter night featuring swaying pine trees, falling snow, and twinkling stars.

## How to Install
1. Download **[Lively Wallpaper](https://rocksdanister.com)**.
2. Click `winter_night.zip` in the file list above and click **Download raw file**.
3. Drag and drop the downloaded `.zip` file directly into your Lively Wallpaper window.
